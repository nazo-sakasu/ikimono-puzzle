# いきものパズル

オリジナルの動物たちで遊ぶ、ブラウザの対戦型落ち物パズルです（ルールは「ぷよぷよ通」準拠）。
PC・スマホ・タブレットで遊べます。サインインは不要です。

## 遊び方

- **ひとりで練習**：通信なしで、好きなだけ連鎖の練習
- **オンライン対戦**
  1. 「オンライン対戦」→ ニックネームを入れて **ルームを作る**
  2. 表示された **招待URL** を友達に送る（「URLをコピー」または「送る」）
  3. 友達がURLを開いて **このルームに入る**
  4. ふたりとも **じゅんび完了** を押すと、3・2・1でスタート

## オンライン対戦の注意

- ルームを作った人のブラウザが、対戦の進行役になります。対戦が終わるまで、その画面を閉じたり、スマホで別のアプリに切り替えたりしないでください。
- つながらないときは、Wi-Fi とモバイル回線を切り替えて試してください（会社のWi-Fiなどでは直接つながれないことがあります）。
- 参加した人は、通信が切れても自動でつながり直します（ページを再読み込みしても同じ試合に戻れます）。20秒戻らなければ不戦敗です。

## 操作

| 操作 | キーボード | スマホ |
|---|---|---|
| 左右に移動 | ← → | 左・右ボタン（長押しで連続） |
| はやく落とす | ↓ | 下ボタン |
| 右に回す | ↑ または X | 右回転ボタン |
| 左に回す | Z | 左回転ボタン |
| 一時停止（練習） | Esc | 左上の ‖ |
